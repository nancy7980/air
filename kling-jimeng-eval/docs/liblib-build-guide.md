# 在 LiblibAI 哩布「在线 ComfyUI」搭建评测工作流（图文步骤）

> 适用：想零本地安装、用哩布每日免费积分跑 **可灵 vs 即梦(Seedance)** 评测的同学。
> 评分沿用本项目的 `dashboard/comparison-dashboard.html`（手动打分），无需 LLM 评委节点。

---

## 为什么哩布版要「现搭」，不能导入现成 JSON

哩布在线 ComfyUI 用的是**自家的一套视频节点**（不是 comfy.org 官方 API 节点）。
本项目 `workflow/kling_jimeng_eval.json` 里是官方节点名（如 `KlingTextToVideoNode`），
**在哩布导入会提示缺节点**。所以在哩布要在画布上**用它自带的节点现搭**——好在只有几个节点，5 分钟。

哩布原生支持的视频模型（截至文档撰写）：可灵 2.6、Seedance 1.5 Pro、海螺、通义万相、Vidu 等，
正好覆盖我们要评的**可灵 + 即梦(Seedance)**。

---

## 准备

1. 登录 [LiblibAI 哩布](https://www.liblib.art) → 顶部进入 **在线 ComfyUI**（`liblib.art/comfy`）
2. 确认账号有**积分**（每日有免费额度；视频按次扣积分，先跑短时长省积分）

---

## 第一步：T2V 文生视频对比（可灵 vs Seedance）

在空白画布上**双击**弹出节点搜索，按下表加节点（搜中文或英文关键词都行）：

| 要加的节点 | 搜索关键词 | 作用 |
|------------|-----------|------|
| 文本/Prompt 输入 | `文本` / `Text` / `String` | 填共享 prompt（受控变量） |
| **可灵 文生视频** | `可灵` / `Kling` | 选 **可灵2.6**，T2V |
| **Seedance 文生视频** | `Seedance` / `即梦` / `字节` | 选 **Seedance 1.5 Pro**，T2V |
| 视频预览/保存 ×2 | `视频` / `Video` / `保存` | 各接一个，看/存输出 |

**连线**：
```
[文本Prompt] ──┬──> [可灵 T2V] ──> [视频预览/保存 A]
               └──> [Seedance T2V] ──> [视频预览/保存 B]
```
> 关键：**同一个文本节点**同时连到两家，保证 prompt 完全一致（公平性）。
> 两家的「时长 / 分辨率 / 比例」也尽量设成一样（如 5s、1080p、16:9）。

跑 **生成/Queue** → 得到可灵、Seedance 两条 T2V 视频。

---

## 第二步：I2V 图生视频对比

再加一组：

| 节点 | 搜索关键词 | 作用 |
|------|-----------|------|
| 加载图片 | `加载图像` / `Load Image` | 上传同一张输入图（受控变量） |
| **可灵 图生视频** | `可灵` / `Kling` | 选可灵，I2V，接收图片+prompt |
| **Seedance 图生视频** | `Seedance` | 选 Seedance，I2V |
| 视频预览/保存 ×2 | `视频` | 输出 |

**连线**：
```
[加载图片] ──┬──> [可灵 I2V] ──> [预览/保存]
[文本Prompt]─┤
             └──> [Seedance I2V] ──> [预览/保存]
（同一张图 + 同一段运动 prompt 同时喂两家）
```

---

## 第三步：评分（用本项目看板，手动打分）

哩布没有 LLM 评委节点，所以评分在看板里手动做（对 PM 作品集反而更能体现你的判断力）：

1. 下载两家视频
2. 打开本项目 `dashboard/comparison-dashboard.html`
3. 把视频填进左右两栏，按 5 维 Rubric 打分（标准见 `docs/evaluation-framework.md`）
4. 雷达图 / 加权总分 / 胜出方实时更新；再补客观指标（耗时、积分成本、成功率）

测试 prompt 用 `docs/test-prompt-set.md` 里的标准 10 条 T2V + 5 条 I2V。

---

## 省积分 & 公平性小贴士

- **先用 5s、低分辨率**跑通流程，确认满意再上高规格，省积分。
- **受控变量**：prompt / 输入图 / 时长 / 分辨率 / 比例，两家必须一致——这是评测可信的前提。
- **seed**：能固定就固定；不能固定则每家多跑 1-2 次取代表作，并在看板里记录。
- 找不到某个节点名？哩布节点库会更新，**双击搜 `可灵` / `Seedance` / `视频`** 总能找到当前可用的那个。

| 平台 | 可灵+即梦 | 装环境 | 花钱 | LLM 评委 | 适合 |

| **哩布在线 ComfyUI** | ✅ 自带节点 | 免装 | 每日免费积分+按次 | ❌（手动打分） | **零安装、想省钱** |

> 你是 Mac Air + 想省钱 → **哩布在线 ComfyUI 是当前最优解**。
